This project is a payload board for pw sat 3. This boards function is to manage and distribute signals between sensors located in the satelite chassie to te main flight controller motherboard.

# Sensors and signals
- Reaction wheels
- AOCS
- EHS
- Camera
- Chamber valves
- Chamber heaters
- Accelelometer
- GNSS

- Presure sensors
- Thermistors

# Reaction wheels
The system incorporates three reaction wheels, each connected to the motherboard through a dedicated 10-pin connector. The corresponding pins of all three connectors are interconnected, forming four shared signal lines: Power, Enable, SCL, and SDA.
The Enable line is connected directly to GPIO pin on the motherboard. The main motor power is supplied by the motherboard and passes through a low-pass filter / RC snubber to reduce current ripple and suppress electrical noise generated by the motors.
The logic supply line is pulled high by the motherboard. The I²C communication lines (SCL and SDA) are also pulled high using 10 kΩ pull-up resistors, providing the required biasing for reliable I²C communication.

# AOCS
The Attitude and Orbit Control System (AOCS) sensor is responsible for providing data required for the spacecraft's attitude and orbit control. The sensor interfaces with the motherboard through a 10-pin connector.
Power for the sensor is supplied directly by the motherboard. The remaining connections consist of an ERR_INT signal, used to indicate sensor errors or fault conditions, and UART RX/TX signals for serial communication.
The ERR_INT interrupt signal is connected directly to a GPIO pin on the motherboard, allowing the system to detect and respond to sensor errors. The UART RX and TX signals are also connected to motherboard GPIOs, providing the communication interface between the AOCS sensor and the main controller.

# EHS
The satellite incorporates three Earth Horizon Sensors (EHS), each connected to the motherboard through a dedicated 4-pin connector.
Power for the EHS modules is supplied by the motherboard and controlled using an integrated load-switch IC. Since all three sensors use I²C communication and share the same I²C address, an I²C multiplexer is used to provide independent communication channels. The multiplexer is implemented using the TMUX131RMGR IC, allowing the motherboard to communicate with each EHS sensor individually.
An I²C repeater, implemented using the PCA9517DGKR IC, is placed between the motherboard and the multiplexer. The repeater provides electrical isolation between the two sides of the I²C interface and allows the EHS-side I²C bus to operate from a separate voltage rail. It also enables the EHS communication interface to be switched on or off independently of the motherboard-side I²C bus.
The dedicated EHS-side voltage rail is controlled using a TPS1HC100 load-switch IC. Its enable (EN) pin is pulled high and controlled by a GPIO on the motherboard, allowing the power supply to the EHS-side circuitry to be enabled or disabled by software.

# Camera
The camera provides two communication interfaces: SPI and I²C. The SPI communication lines are connected directly to the corresponding pins on the motherboard, providing the primary high-speed communication interface with the camera.
The camera also includes an Enable signal, which is driven directly by a GPIO on the motherboard, allowing the camera to be enabled or disabled by software.
Similarly to the EHS interface, the camera's I²C interface incorporates a PCA9517DGKR I²C repeater and a TPS1HC100 load-switch IC. The I²C repeater provides separation between the motherboard-side and camera-side I²C bus and allows the camera-side interface to operate from a dedicated voltage rail. The TPS1HC100 load switch controls this dedicated power rail, allowing the camera-side I²C interface to be powered on or off independently.
The enable (EN) pin of the TPS1HC100 is controlled by a motherboard GPIO, providing software control over the power supplied to the camera-side I²C circuitry.

# Accelelometer
The ASM330LHHXTR sensor IC provides both 3D accelerometer and 3D gyroscope measurements, enabling the system to monitor linear acceleration and angular velocity along all three axes.
The sensor is connected directly to the motherboard through the I²C interface, which is used for configuration and communication with the sensor.

# Chamber valves
The valves located before and after the heating chamber are connected to the motherboard through 4-pin connectors. Both valves require a 24 V supply voltage, which is generated by stepping up the 18 V supply provided by the motherboard.
The motherboard controls the valves by switching their power supply on and off using switches configured in a "Quad Redundant Switching configuration". This allows the valves to be individually controlled by the motherboard while providing protection against switch failure.
